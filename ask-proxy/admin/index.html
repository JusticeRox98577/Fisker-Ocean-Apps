            Knowledge to review

            Fault code meanings, fixes and car facts owners offered in "Any questions?", oldest first. Nothing is used in answers until you approve it. Edit the title and text first: keep only what the owner said, drop anything personal, and never add specs or prices nobody confirmed. Who sent it is never shown.

              Approved notes

              Every note that isn't retired goes into every answer, after the guide, newest first (about 20,000 characters at most). Changes reach answers within about a minute.

                Feedback

                Feedback about the app that owners gave in "Any questions?", newest first. It never goes into answers. Who sent it is never shown. Mark it done once it's dealt with, or add it to the roadmap (you write the public title and text; that marks it done too).
