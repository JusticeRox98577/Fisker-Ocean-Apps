RAC

Rear climate

  1. Home
  2. Modules
  3. RAC

RAC is the rear climate module, one of the 39 modules Ocean Live reads fault codes from with Faults→Scan all modules. The owner guide lists it as RAC (rear climate).

What the app can do

  • Read its stored fault codes, and its software version and part number with Faults→Module versions→Read module versions (reading changes nothing).
  • Clear codes for this module, only while parked safely. Share the report first: clearing erases the history a workshop would use.
  • This module doesn't support a restart, so Ocean Live doesn't offer one. Clearing its codes is still possible.
